# مدير الدواجن اللاحم — مشروع أندرويد

التطبيق كله في `app/src/main/assets/index.html`، ويعمل بدون إنترنت. البيانات تُحفظ على الهاتف فقط.

## الطريقة 1: إخراج APK عبر GitHub (بدون تثبيت أي برنامج)
1. أنشئ حساباً على github.com، ثم أنشئ مستودعاً جديداً (New repository)، ويُفضَّل أن يكون Private.
2. اضغط **uploading an existing file** وارفع كل محتويات هذا المجلد (مع مجلد `.github`).
   - إذا لم تظهر المجلدات المخفية، فأنشئ الملف يدوياً: **Add file ← Create new file** باسم
     `.github/workflows/build-apk.yml`، والصق محتواه.
3. افتح تبويب **Actions**. سيبدأ البناء تلقائياً ويستغرق 4–6 دقائق.
4. عند ظهور ✅ افتح البناء، ونزّل **BroilerManager-apk** من أسفل الصفحة. ستحصل على ملف zip فيه `app-debug.apk`.
5. انقل الملف إلى الهاتف وثبّته (اسمح بالتثبيت من مصادر غير معروفة).

## الطريقة 2: Android Studio
افتح المجلد في Android Studio، ثم اختر **Build ← Build APK(s)**.

## التحديث لاحقاً
عدّل `index.html` وارفعه مكان القديم، فيُبنى APK جديد تلقائياً. البيانات تبقى ما دام اسم الحزمة (`com.farm.broiler`) لم يتغير.

## مهم
- صدّر نسخة احتياطية من **المزيد ← الإعدادات** أسبوعياً، فحذف التطبيق يحذف بياناته.
- التشخيص والتوصيات مساعدة فقط، والقرار الطبي للطبيب البيطري.
